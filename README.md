# URL Shortener

A simple command-line URL shortener supporting TinyURL and Bitly.

---

## Overview

This project provides a CLI tool to shorten long URLs using either TinyURL (free, no API key) or Bitly (requires API key).

## Installation

### Option 1: Download Pre-built Binaries (Recommended)

You can download ready-to-run executables for Windows, macOS, and Linux directly from [GitHub Releases](../../releases).

1. Go to the **[Releases](../../releases)** page.
2. Download the binary for your operating system under **Assets**:
   - **Windows:** `url-shortener-windows.exe`
   - **macOS:** `url-shortener-macos`
   - **Linux:** `url-shortener-linux`

---

#### macOS / Linux Setup
Before running the executable on macOS or Linux, grant it execute permissions:

```bash
# macOS
chmod +x url-shortener-macos

# Linux
chmod +x url-shortener-linux
```

### Option 2: Install via pip (Python 3.8+)

If you have Python installed, you could also install it directly from the GitHub repository:
```bash
pip install git+[https://github.com/zaylinkhant02/URL-shortener.git](https://github.com/zaylinkhant02/URL-shortener.git)
```
